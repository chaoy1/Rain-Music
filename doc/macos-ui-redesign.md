# macOS 风格界面改版

2026-10-04，第十二版。本地 Windows / Electron 42 验证。

- 窗口交通灯移至真正的左上角。红灯使用原有关闭窗口逻辑；开启托盘时隐藏窗口，关闭托盘时正常关闭。绿灯切换全屏，并在全屏中保留退出入口。
- 使用原生窗口焦点事件控制失焦灰态，增加键盘焦点提示和快速重复点击保护。
- 内容区四角使用相同圆角，右侧保留 10px 间距。侧栏、工具栏和播放条共用连续的磨砂底色，圆角外不再露出不同色的矩形底层；显式裁切滚动内容与子页面。
- 全屏请求按顺序执行，等待原生窗口事件完成后读取实际状态，避免事件回调内读取到上一状态。进入全屏时允许窗口调整大小，退出后恢复。原生全屏变化同步按钮和页面状态；被系统拒绝的切换会恢复可操作状态。
- 分页使用独立圆角页码、常规字重、细线箭头与明确的首末页数字。省略号只表示间隔，当前页支持键盘焦点，首末页正确禁用前后翻页。
- 银灰与炭黑主题采用统一的面板、边缘、卡片、弹层和选中状态。降低桌面壁纸的饱和度与透出强度，避免正文被壁纸染色。
- 银灰使用中性铝银底色、浅色磨砂内容与细颗粒；炭黑使用独立石墨基底，修正旧深色主题叠在浅灰底上而发白的问题。图标、控件、主题色样与材质高光统一为中性灰阶。
- 搜索移入搜索页音源切换下方、热门搜索上方，顶部只保留页面标题；侧栏保留搜索入口。搜索框为 42px 高、最大 600px 宽，未聚焦时使用低对比底色与细边缘，聚焦时显出柔和高光、边框与浅阴影，两种状态在 180ms 内过渡并保持位置与尺寸。支持回车、普通字重候选和原有搜索快捷键；切换页面后重新进入仍显示当前搜索词，提交时保留音源与搜索类型。最小窗口内仍能完整操作搜索和滚动热门/历史词。
- 启动进入“我的列表”，保留该页面上次选择的列表；随后处理显式启动参数和深链接。底部始终使用全宽时间轴，可直接拖动与键盘调整；旧迷你/中间偏好均兼容到全宽，移除失效的进度样式设置。
- 修正延迟加载业务模块后错过 Electron ready 事件的问题，立即初始化屏幕工作区，使桌面歌词能创建原生窗口。桌面歌词提供启用状态、无歌词提示、圆角磨砂面板和统一的悬停/按下反馈。构建仅替换指定环境常量，保留运行时数据目录环境变量，保证独立验证目录生效。
- 磨砂底层使用低饱和壁纸、40–48px 背景模糊和原创 SVG 细颗粒纹理。正文使用连续的圆角面板，工具栏和播放条融入同一材质。
- 通用按钮使用统一的悬停底色、轻微按压缩放、内陷阴影与键盘焦点；按压 70ms 响应，180ms 恢复，禁用按钮不响应，系统减少动态效果和软件动画开关均生效。工具栏、列表操作、分段切换、分页和设置共用此规则。普通按钮采用浅磨砂底色与克制的边缘高光。播放控制和辅助控制分别共享一组底色；复选框、单选框、输入框、菜单和对话框采用同一控件色板。
- 移除全部鼠标跟随光圈与径向反光，保留静态磨砂颗粒、材质高光和正常按钮悬停反馈。选中、多选与正在播放的歌曲行使用 12px 圆角与极浅灰渐变，降低底色与边缘高光的强度并移除外侧阴影；银灰与炭黑各自适配，虚拟列表行高保持原值。
- 按钮从正圆/胶囊收敛为柔和圆角矩形：普通按钮 10px、主要播放控件 12px、侧栏 11px，仍保留边缘高光、浅阴影及按压反馈；交通灯与封面几何保持独立。
- 桌面歌词为白色磨砂底的 116px 高两行浮窗，默认宽度 460px，打开时将旧的更宽配置收敛到 460px，仍可手动调整宽度。背景渐变不透明度降至 66–78%，弱化边缘并压缩两行间距，独立于主窗口深浅主题。当前句为深绿色，下一句为中性灰绿；有逐字时间信息时使用原有动画引擎按演唱进度染绿，修正跳到词中间时动画从头开始的问题，暂停保持当前高亮位置。只挂载当前行的歌词引擎节点与下一句文本，移除重复的阴影文本和翻译行；末尾保留空的下一句位置，切歌与停止状态同步更新。歌词区域可直接拖动，悬停仅显示锁定与关闭两个操作；设置保留启用、锁定、置顶、暂停隐藏、字号和重置位置。最小宽度为 360px，字号兼容旧设置并限制在 16–28px。
- 打开歌词时自动开启原生置顶并清除旧全屏隐藏偏好，创建后显式使用 `screen-saver` 层级；主窗口显示、获取焦点或切换全屏时重新确认层级，并抬升歌词窗而不抢焦点。最小化主窗口时歌词继续显示，全屏切换不再销毁歌词窗。设置中仍可主动关闭置顶，重新打开歌词时恢复置顶；移除跨窗口沿用的置顶状态缓存，避免重开后开关与原生状态不一致。
- 普通页面保留底部播放条。点击封面后，详情铺满整个应用窗口，侧栏、工具栏与原播放条隐藏并退出键盘和鼠标交互；左侧展示封面与歌曲信息，右侧保留大面积歌词。原页面继续挂载，保留路由与滚动位置。
- 新增共用播放控制组件，详情及三种底部播放栏使用同一套原创 24px 矢量图标。详情侧按钮等宽，中间控制严格居中；按钮命中区域 40–52px，图标具有光学居中补偿。左下方的轻磨砂控制面板仅保留进度、时间、上一首、播放/暂停、下一首、播放模式和添加到歌单。进度采用 Pointer Events 与指针捕获，按下立即预览位置，拖动期间无补间延迟，释放时提交一次；取消不会改变进度，跨出边界正确限幅。命中区域至少 24px，并支持方向键、Home/End 操作；不重复展示右侧的当前歌词，专辑名与歌曲名相同时省略重复信息。
- 详情页保留歌词滚动与逐字高亮，移除评论、文本选择工具、音效、速度和可视化入口。播放模式通过一个按钮依次切换顺序播放、列表循环、单曲循环和随机播放，不再提供禁用切歌。启动时恢复标准音效和速度，旧禁用切歌配置恢复列表循环，其他配置保持原值。
- 右上角收起按钮、Esc 或双击右键关闭详情；程序导航到其他页面时也会退出。底层页面更新搜索参数不会打断详情和动画。详情保留交通灯与可拖动标题区，绿色按钮控制原生全屏。
- 打开时封面从底部入口展开，歌词、信息和控制面板轻微错峰淡入；关闭时封面缩回入口。使用合成层变换与透明度，关闭动画完成后恢复页面交互与入口焦点。快速关闭可从当前动画位置衔接，禁用动画及系统减少动态效果时立即切换。
- 音量与桌面歌词均放在详情页外的普通底部栏。音量默认只显示扬声器；悬停、点击或键盘聚焦时展开 210px 磨砂面板，水平滑杆具有 32px 命中区域。离开后延迟 420ms 收起，拖出弹层时保持展开，松开再收起；支持 1% 键盘微调、滚轮与静音后直接拖动恢复。Esc、外部点击、窗口失焦、调整尺寸和打开详情均会关闭音量面板。详情保留封闭的键盘焦点循环，底层控件不可聚焦。
- 搜索候选与历史词使用普通字重；选中候选通过浅底色标示。来源与类型切换采用统一的分段控件。
- 歌单采用封面优先的竖向排布，收敛独立卡片边框，小窗口自动使用两列。歌单详情、榜单、我的列表、下载与设置页采用相同的间距和材质。
- 设置分组改用留白和细分隔线，统一次级导航的圆角选中状态，收敛滚动条和空状态字号。银灰、炭黑主题预览展示对应的面板颜色。
- 主题初始化与切换同步深色类、系统控件色调和实际颜色。主进程主题通知直接刷新颜色，避免同一主题 ID 下更新被忽略。
- 修正最小窗口下的列表标题空间，列表无需滚动时不再常驻滚动条。

## 验证

运行 `npm run test:window-controls` 可在 Chromium 中验证真实交通灯组件，替换的只有 IPC 边界。测试覆盖关闭、最小化、快速点击、全屏状态同步、全屏退出入口和失焦状态。

运行 `npm run test:pagination` 验证当前页语义、前后翻页、首末页禁用、跳页和单页隐藏。

先构建主进程与渲染进程，再运行 `npm run test:surfaces` 验证实际应用。测试使用独立数据目录，覆盖 Chromium 鼠标输入下光圈保持移除、详情按需挂载和退出恢复、普通字重搜索候选、复选框设置与可访问状态同步、六个主页面的深浅主题、歌单卡片与分页布局、四角内容裁切、828×540 小窗口、三种播放条及真实关闭/最小化/全屏交互。窗口检查还覆盖原生进入与退出、连续切换及尺寸恢复、切换被拒绝后的恢复、Chromium 鼠标点击、F11 进入和 Esc 退出。

歌单卡片与搜索词由测试注入，用于验证布局，不代表在线音源请求成功。检查结果及截图：`.design/refined-app-results.json`、`.design/refined-*.png`。

本版构建与检查日志：`.design/edges-renderer-build.log`、`.design/edges-main-build.log`、`.design/edges-lint.log`、`.design/edges-surfaces-green.log`、`.design/edges-pagination-green.log`。修复前的失败证据保存在 `.design/edges-surfaces-red.log` 和 `.design/edges-surfaces-debug.log`。

## 设计参考

- [Apple：Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass?changes=_2_11)：控件按功能分组，克制地使用玻璃效果，避免多层控件互相叠压。
- [Apple Music 官方界面展示](https://www.apple.com/newsroom/2025/06/macos-tahoe-26-makes-the-mac-more-capable-productive-and-intelligent-than-ever/)：以内容、封面和侧栏层次组织音乐界面。
- [Apple Music MiniPlayer 官方指南](https://support.apple.com/en-euro/guide/music/mus71d7dcfce/mac)：紧凑布局与悬停显示操作的参考。本版两行歌词浮窗为项目原创实现。
- [Spotify Premium 官方使用指南](https://newsroom.spotify.com/2024-04-11/spotify-premium-tips-tricks/)：参考可移动的小型桌面播放器组织方式。
- [Electron 原生窗口层级](https://www.electronjs.org/docs/latest/api/base-window#winsetalwaysontopflag-level-relativelevel)：使用高于 Windows 任务栏的置顶层级，并通过原生窗口事件重新确认。

外部资源仅用作设计参考；未把 Apple 的图像或图标打包进应用。细颗粒 SVG 纹理为本项目新增的代码资产。

本次验证覆盖界面与窗口交互；未验证在线音源、下载和带实际歌曲的播放。未在 macOS 设备上运行测试。

预览程序：`preview/rain-music-preview.exe`。更新保留 `preview/portable` 中的配置与数据库，并在启动前校验原有文件哈希。应用内玻璃效果通过 CSS 模糊、透明度与光照模拟。
